# Personal Dashboard & Live Clock

An ambient, glassmorphic personal dashboard featuring a high-precision digital clock, dynamic time-of-day greetings, customizable user identity, global timezones, and productivity tools.

## ✨ Features

- **Personalized Identity**: Click-to-edit your name and tagline directly on the screen, automatically saved to your browser (`localStorage`).
- **Live Master Clock**: Sub-second precision digital clock with 12H / 24H toggle and animated seconds track.
- **Dynamic Time Greeting**: Context-aware greetings (*Good Morning*, *Good Afternoon*, *Good Evening*, *Good Night*) with status badges.
- **World Clocks**: Real-time synchronized time for Tokyo, London, New York, and UTC.
- **Productivity Focus Timer**: Integrated 25m / 5m / 15m Pomodoro countdown timer with tab title sync.
- **Ambient Themes**: Instant switching between **Aurora Emerald**, **Cyber Violet**, and **Sunset Coral** color atmospheres.
- **Quick Access Dock**: Direct launch tiles for GitHub, X (Twitter), LinkedIn, and Email.
